# posture_police

A trained AI system made in tensor to correct posture when slouching while deploy streamlit for UI.

## Features (WIP)

- Beeps when slouching
- Slider to adjust when slouch vs not slouch
- Webcam tracking
- posture statistics
- OPTIONAL :
- customizable alerts to prevent fatigue
- simple stretches (make the config like plantify)
