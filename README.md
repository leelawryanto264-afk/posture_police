# posture_police

A trained AI system made in tensor to correct posture when slouching while deploy streamlit for UI.

** If someone is serious on wanting better posture here is a youtube video that helps you stretch and explain why people slouch:  . Think of the website as a supplement not a cure 
*** WARNING: DO NOT try to straighthen your back repeatedly if you have a spine related injury or pain, it can make it worse
## Features (WIP)

- line turns red when slouching
- Slider to adjust when slouch vs not slouch
- Webcam tracking
- posture statistics
- OPTIONAL :
- Beeps when slouching
- customizable alerts to prevent fatigue
- simple stretches (make the config like plantify)
